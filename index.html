Demos of Linear and Tree-based Data Structures

Interactive demos for Data Structures. Make changes, watch the structure change, and follow the pseudocode line by line as each operation runs.

Designed and debugged by David Frazier. Created by Claude AI.

  1. Linear Data Structures Stack and Queue Demo, implemented with both Arrays and Linked Lists. combined_demo.html
  2. Binary Search Trees Operations, with the matching pseudocode highlighted as each step runs. Useful for connecting the picture to the code you write. bst_demo_pseudocode.html
  3. AVL trees Insert values and watch balance factors update. When the tree gets lopsided, see which rotation fixes it and the code behind it. avl_demo_pseudocode.html

Things to try

  • Insert 10, 20, 30, 40, 50 into a plain BST. What shape do you get, and how long does a search take?
  • Insert the same values into the AVL tree and count the rotations.
  • Delete a node with two children and watch which value replaces it.
