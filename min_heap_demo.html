This is pseudocode, not C++, but it is the same Min-Heap you will build for Portfolio 3A: A stands in for your std::vector<T>. INSERT grows A by one element and calls HEAPIFY-UP; EXTRACT-MIN moves the last element of A into the root, shrinks A by one, and calls HEAPIFY-DOWN. The array view and the tree view show the same data: a heap is a tree, stored as an array, where node i's children live at 2i + 1 and 2i + 2.
